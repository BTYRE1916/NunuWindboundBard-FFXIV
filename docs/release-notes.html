RELEASE NOTES / v0.39

What's new.

A guided tour of the changes from Solo Stage and instrument icons to Piano Academy, Showmaster and the Dark Stage interface.

Source version and release tag are different. The website describes the v0.39 source feature set. GitHub releases use tags such as FFXIVMIDIPLAYER-v1.40. Check your installed plugin and release notes to know exactly which features are present.
v0.39

Dark Stage UI

Six grouped workspaces (PERFORMANCE, BAND, STUDIO, SHOW, TOOLS, SETUP), an illustrated concert header, status chips, optional neon accents, a plain-colours fallback and reduced-motion controls. The existing playback engine and party protocol remain unchanged in this update.

Navigate v0.39 →
v0.38.1

Full Showmaster emote library

Select from emotes unlocked on the conductor's character, check follower availability, choose bow fallbacks or skip missing actions and start group routines only between songs.

Showmaster guide →
v0.38

Piano Academy and Showmaster

Original-range MIDI falling notes with 88-key lessons, wait/play-along modes and a detached practice view; plus choreographed intermission emotes.

Piano Academy →
v0.37.3

Band portraits and crop fix

Dedicated portrait manager visible even in Solo mode, local Adventurer Plate capture and a draggable square crop selection.

Band Portraits →
v0.37.1

Native instrument-switching improvements

Wait for the previous Performance instrument to stow before changing models, with native unequip and safe retries. Still requires verification against the installed game build.

v0.36.1

Aligned instrument icons

Corrected the display offset for the game's Performance icons; instrument IDs and MIDI logic remain unchanged.

v0.35

Solo Stage and automatic facing

Standalone stage movement without a party and facing controls for saved band formations, using optional vnavmesh navigation.
