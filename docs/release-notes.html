RELEASE GUIDE / v0.47.3

What's new.

From the native capture engine to MIDI Workbench: follow the latest additions and the earlier tools that make up today’s Windbound studio.

Plugin version: 0.47.3.0. Release tag 0.47.3. Open the published release →
v0.47.3

Follower START settings fix

Network followers use the conductor’s playback speed for the current take without saving plugin settings during START. A failed START now records the exception in the follower’s Dalamud log.

v0.47.2

Default Hosted Band relay

Hosted Band uses the Windbound Cloudflare relay by default. Conductors can select Host Band immediately or enter a custom relay address. Followers join with the conductor’s code.

v0.47.1

Hosted Band timing

Hosted Band timestamps clock probes at send time and restores first-note timing reports. Each follower can enter an exact timing trim and see the value used on the last START.

v0.47.0

Cloudflare relay option

The full project includes a Cloudflare Workers relay for Hosted Band. The conductor enters the deployed relay address and shares a join code with followers.

Set up Hosted Band →
v0.46.3

Concert Director for hosted bands

Choose songs, set instruments and tracks, arm participating performers, and start the band from the Ensemble tab.

Hosted ensemble controls →
v0.46.2

Windows conductor handshake

Hosted Band uses a current-user private key for Windows TLS. If the conductor reported 0x8009030E after attaching to the relay, update Windbound and host a fresh room.

Relay troubleshooting →
v0.46.1

See why a hosted band disconnected

Both clients can copy a timed relay report. Match the connection reference to the relay log to see where pairing or live traffic stopped.

Read a relay report →
v0.46.0

Host a band and share a join code

Hosted Band uses a connected roster for MIDI assignments, readiness, and synchronized cues. The release includes the relay service.

A native MIDI preparation tab with piano-roll note editing, track tools, drum maps, undo/redo, C3–C6 adaptation, beat-aware quantization, SoundFont preview and MIDI/LRC export. Tempo, octave metadata and Unicode titles are preserved through export.
