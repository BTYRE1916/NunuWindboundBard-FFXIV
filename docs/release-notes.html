RELEASE GUIDE / v0.44.3

What's new.

From the native capture engine to MIDI Workbench: follow the latest additions and the earlier tools that make up today’s Windbound studio.

Current release: 0.44.3.0. Release tag 0.44.3. Open the published release →
v0.44.3

Shortcut Bars

Build dockable bars for FFXIV and plugin commands, bind a radial menu, and share layouts.

Read the guide →
v0.44.2

Low-render follower camera

Background followers in Performance can point the camera at the ground with a narrower field of view. Focus a follower to bring back its normal view.

Read the guide →
v0.44.1

Same-PC song sync

Followers receive the conductor’s MIDI files in their active Ensemble playlists. Match the stage name and enable sharing on each client.

Read the guide →
v0.44.0

MIDI Editor

A direct piano roll with note dragging, resizing and box selection. Adds expression lanes, timeline tools, local playback, MIDI device routing, and keyboard takes.

Read the guide →
v0.43.1

Hide the native Performance HUD

Hide the performance keyboard, guitar tone selector and metronome while their game windows stay open for playback. The Dark Stage header displays the current plugin version.

Get the published installer →
v0.43.0

MIDI Workbench

A native MIDI preparation tab with piano-roll note editing, track tools, drum maps, undo/redo, C3–C6 adaptation, beat-aware quantization, SoundFont preview and MIDI/LRC export. Tempo, octave metadata and Unicode titles are preserved through export.

Explore Workbench →
v0.42.5

Bassdrum name mapping

Bassdrum spelling variants select Bass Drum (ID 12), while Bongo remains 11. Specifically named percussion parts take priority over GM drum-note guessing.

Instrument mapping help →
v0.42.4

MP4 output and HD capture preview

MP4/MKV recording and replay output selection, 540p/720p/1080p preview choices, adjustable preview refresh rate and a separate large preview window.

Recording and preview guide →
v0.42.3

Memory-load startup fix

Bundled capture paths resolve through the plugin’s Dalamud assembly location, so configuration can load correctly when Dalamud loads the DLL from memory.

Engine update help →
v0.42.0–0.42.1

Native Windbound capture suite

Separate Windows capture and encoding engine, plugin-side scene and output controls, source transforms, audio mixing, replay and streaming controls. Solution and package-source fixes support building both projects.

Meet the native suite →
v0.39

Dark Stage UI

Six grouped workspaces (PERFORMANCE, BAND, STUDIO, SHOW, TOOLS, SETUP), an illustrated concert header, status chips, optional neon accents, a plain-colours fallback and reduced-motion controls. The existing playback engine and party protocol remain unchanged in this update.

Navigate v0.39 →
v0.38.1

Full Showmaster emote library

Select from emotes unlocked on the conductor's character, check follower availability, choose bow fallbacks or skip missing actions and start group routines only between songs.

Showmaster guide →
v0.38

Piano Academy and Showmaster

Original-range MIDI falling notes with 88-key lessons, wait/play-along modes and a detached practice view; plus choreographed intermission emotes.

Piano Academy →
v0.37.3

Band portraits and crop fix

Dedicated portrait manager visible even in Solo mode, local Adventurer Plate capture and a draggable square crop selection.

Band Portraits →
v0.37.1

Native instrument-switching improvements

Wait for the previous Performance instrument to stow before changing models, with native unequip and safe retries. Still requires verification against the installed game build.

v0.36.1

Aligned instrument icons

Corrected the display offset for the game's Performance icons; instrument IDs and MIDI logic remain unchanged.

v0.35

Solo Stage and automatic facing

Standalone stage movement without a party and facing controls for saved band formations, using optional vnavmesh navigation.

Stage Formations →
