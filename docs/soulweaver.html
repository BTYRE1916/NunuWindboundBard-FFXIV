One song.
A whole ensemble.

STUDIO → Soulweaver Studio

A melody.
Many musicians.

Soulweaver analyses a prepared arrangement and allocates melody, bass, harmony and other musical roles into Solo, Duet, Quartet or Octet parts. It uses deterministic musical heuristics; review the result by eye and ear.

Generate and review

  1. Load a MIDI in PERFORMANCE → Songs & Playback.
  2. Open STUDIO → Soulweaver Studio and choose 1, 2, 4 or 8 musicians.
  3. Choose whether to analyse all non-percussion tracks or respect your current track mutes.
  4. Set a per-performer chord limit, or leave 0 for unlimited prepared notes.
  5. Select Analyse & Generate Parts. Inspect the part timeline, ranges, note counts and warnings.
  6. Choose instruments and optional party assignments, then export or add the result to a Solo/Ensemble playlist.

Keep the music in context

Exports preserve the source tempo changes and create a named track for each musician. A source MIDI is not overwritten. A small chord cap can simplify dense parts; unlimited keeps all prepared notes.

Refine the result in Workbench

Load the exported arrangement into MIDI Workbench to edit individual notes, merge or split parts, adjust instruments and finish the drum arrangement. Use SoundFont preview for local rehearsal.

Take the band on stage

Each performer still needs the matching MIDI locally and a ready Performance instrument. Use the native Ensemble workflow to assign parts and coordinate the start.
