Set up a SoundFont preview

  1. Choose an SF2 SoundFont you have permission to use.
  2. Open STUDIO → Audio Preview, browse to the .sf2 file and save its path.
  3. Choose the original MIDI, prepared Windbound arrangement or a selected track.
  4. Set volume and speed, then start audio preview with game playback stopped.

Workbench also offers Preview enabled parts and Solo selected using the same SoundFont setting. Instrument sounds are General MIDI approximations; they can differ from the instruments you hear in FFXIV.

SoundFont preview plays through the local computer. It does not broadcast audio to the party or send Performance notes into the game. SoundFont files are supplied by the user.

Connect a physical MIDI keyboard

Use PERFORMANCE → Live MIDI Piano to select a compatible Windows MIDI input device. Configure the input channel, transpose, range folding and sustain behavior for the part you want to play.

For falling-note lessons and the original A0–C8 range, use Piano Academy. Its practice input is separate from the regular Performance output.
