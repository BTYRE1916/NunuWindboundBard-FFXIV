Editing the MIDI itself? The MIDI Editor adds direct piano roll gestures, controller lanes, tempo tools and MIDI recording. Save and send the arrangement here to prepare FFXIV parts.

Start with a MIDI file or copy the song loaded in Windbound’s player. Workbench keeps an independent working copy, so you can prepare an arrangement without changing the source file.

The quick workflow

  1. Open STUDIO → MIDI Workbench, then choose Import MIDI… or Copy current player MIDI.
  2. Click a part to make it active. Check Select for multi-part edits; Use controls full preview and export.
  3. Set an instrument and octave tag. In the piano roll, select a note to edit pitch, velocity, start and duration—or add and delete notes.
  4. Prepare the parts with the track, note and drum tools below.
  5. Choose Preview enabled parts or Solo selected with a local SF2 SoundFont.
  6. Use Export MIDI as…, or Export, add to library & load. The exporter reopens the new MIDI to check it.

Track and note tools

Shape the parts

Rename, reorder, duplicate or remove tracks. Merge selected tracks using the active instrument, or split overlapping notes into single-note voices.

Refine the notes

Transpose, adapt pitched parts to C3–C6, remove duplicates, trim same-pitch overlaps, extend sustain, quantize starts and ends, or limit sustained polyphony.

Quantization follows beats across the original tempo map. The voice cap deliberately drops notes while all voices are occupied; Undo restores them. Undo and Redo keep up to 20 editing snapshots.

A drum kit becomes named FFXIV parts

Open Drum split and custom pitch map to route GM hits into Bass Drum, Snare Drum, Bongo, Cymbal, Timpani or Other Percussion. Set a destination and target pitch for each hit, and choose whether to retain GM pitches or convert them.

Unmapped hits remain in Other Percussion. The default map leaves hi-hats and rides there for manual review. Unchecking Keep deliberately removes that source hit.

Already edited drums? Named FFXIV parts such as Bassdrum are preserved. Enable Treat active part as a General MIDI drum kit only when the part really contains GM drum identifiers. Bass Drum uses instrument ID 12; Bongo uses 11.

One octave shift, applied once

The piano roll shows stored MIDI pitches. Preview applies the part’s octave tag, and export preserves it. Bake octave tags into notes applies that shift to the working copy and clears the tag. C3–C6 adaptation also resolves the octave tag.

Export for the next performance

MIDI export preserves the source tempo map, meter, key and lyric events, with explicit instrument tags for Windbound. The source and existing output files stay intact. Export source lyrics (.lrc) writes timestamped lyric events when present.

Export-and-load adds one enabled part to the Solo library or multiple parts to the Ensemble library. If a performance is running, the new arrangement is saved to the library and waits for you to stop playback before loading.

ⓘWorking copies last for the current plugin session. Export before unloading or importing another song. Note durations follow Windbound’s 35–60,000 ms reader range. Standard MIDI supports 15 distinct melodic program sounds plus drums; the exporter reports channel-capacity problems instead of silently losing notes.
