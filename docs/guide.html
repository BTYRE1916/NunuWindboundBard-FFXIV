Chapter 01

Install Windbound Bard

You’ll need FFXIV, a compatible Dalamud environment, and the Windbound Bard plugin. The published repository currently offers an install manifest for Dalamud.

  1. Launch FFXIV with Dalamud, then enter /xlsettings in chat.
  2. Open Experimental → Custom Plugin Repositories.
  3. Paste the custom repository URL below, select +, enable the entry and choose Save and Close.
  4. Enter /xlplugins, search for Nunu’s Windbound Bard and install it.
  5. In chat, enter /windbound to open the player.
https://raw.githubusercontent.com/BTYRE1916/NunuWindboundBard-FFXIV/master/Plugin.json
ⓘFor a source/development build, use Dalamud’s Dev Plugin Locations as described in the complete manual. Custom repos are third-party software and are not vetted by Dalamud’s main repository.
Chapter 02

Play your first MIDI

  1. Use /windbound to open the plugin.
  2. Go to BAND → Ensemble and choose Solo.
  3. Open PERFORMANCE → Songs & Playback. Load the bundled Bard-37-Note-Calibration.mid or browse for your own .mid file.
  4. Choose a Performance instrument and open the full 37-key Performance interface.
  5. Enable ARM: Direct FFXIV Performance notes. This is the safety switch that allows notes into the game.
  6. Use TOOLS → Direct Output & Test to try C4, then press Play in the Performance workspace.

What does ARM mean?

Without ARM, the timeline may progress without sending notes to FFXIV. Windbound does not restore ARM after a plugin restart—you deliberately enable it for every new session.

Chapter 03

37 keys. One full range.

Playback uses native FFXIV Performance callbacks. The key reference below is provided for the keyboard diagnostic controls; the plugin does not send global Windows keystrokes to type notes.

The plugin’s default chromatic range is C3–C6, corresponding to MIDI 48–84 inclusive. Choose expanded Performance, not mini keyboard mode, and use the matching key mapping.

Chapter 05

From duet to octet

Use native FFXIV Ensemble for coordinated starts. Each Bard needs the same plugin version, the identical MIDI available locally, a Performance instrument and the expanded keyboard.

On the conductor

  1. Be the actual in-game party leader ; choose Conductor under BAND → Ensemble.
  2. Load the MIDI into your Ensemble library.
  3. Assign each track/channel to a Bard; use SET PARTY TRACKS.
  4. Use SET PARTY INSTRUMENTS, or Concert Director’s PREPARE ENTIRE ORCHESTRA.
  5. Press ARM ALL BARDS and wait for readiness acknowledgements.
  6. Press START ENSEMBLE — FFXIV Ready Check.

On each follower

  1. Select Follower and enable the native Ensemble option.
  2. Permit leader MIDI/instrument sync and optional ARM control as desired.
  3. Ensure the same MIDI file exists in that client’s library and Performance is ready.
  4. Allow automatic FFXIV Ensemble Ready Check acceptance if appropriate, or accept manually.

Important: the conductor sends a MIDI fingerprint, not the actual file; matching file names alone may not be enough. The game’s native cue starts the song, not a party-chat countdown.

Chapter 06

Design your stage

Open BAND → Stage Formations to save and recall the orchestra’s positions, or use the Solo Stage controls without joining a party. The visual designer can save both placement and facing; optional vnavmesh walks to each selected spot. This system is experimental and requires a supported FFXIV/Dalamud build.

  1. For ensemble movement, bring the party to the same stage, housing ward and instance. Solo Stage needs no party.
  2. Open BAND → Stage Formations. For a band, the actual party leader selects Conductor; for yourself, use Solo Stage.
  3. Enable the experimental visual designer, anchor your stage, and choose a line, arc, circle or two-row template.
  4. Drag performer dots, assign Bards, then save the diagram.
  5. Only when all clients are idle, out of combat and Performance, explicitly request SET POSITIONS & MOVE PARTY.
⚠Movement is opt-in and subject to safety/path checks; it never teleports. In supported builds, the character can face the saved direction after walking to the stage spot. Movement is never an automatic part of MIDI playback.
Chapter 07

Find your tools in Dark Stage

Windbound groups the performance and creative tools into six workspaces. MIDI Workbench is in STUDIO; Concert Capture is in SHOW.

In SETUP → Appearance, select Soul Rose, Void Violet or Aether Cyan, enable reduced motion, or switch back to plain colours.

Chapter 08

Learn a MIDI with Piano Academy

  1. Connect a USB MIDI keyboard or synthesizer to Windows, then open STUDIO → Piano Academy.
  2. Load a lesson MIDI using Browse lesson MIDI, or use a MIDI already loaded in Songs & Playback.
  3. Select the track and choose Wait for correct notes or Play Along.
  4. Refresh MIDI ports, select your piano, then connect. Turn on the lesson input option.
  5. Choose your speed and keyboard range, then open the detachable practice window if desired.
Rehearsal only: Piano Academy reads the original MIDI pitches and does not transmit lesson notes into FFXIV. Loop controls apply to Play Along mode.

Chapter 09

Build an intermission in Showmaster

  1. Open SHOW → Showmaster after ending MIDI playback and stowing Performance instruments.
  2. Refresh your unlocked emotes, search the catalog and create a custom routine with up to 12 steps.
  3. Use Run local to try it on your own character.
  4. For an ensemble, followers select Follower and enable their Showmaster permission. The party leader chooses CHECK BAND EMOTES.
  5. Review availability and use GROUP SHOW when everyone is ready. Missing emotes can optionally fall back to a bow.

Emotes are executed by each player's own client; the conductor's unlocks do not unlock them on other accounts. Full Showmaster guide →

Chapter 10

Set up in-game Band Portraits

  1. Open the character's Adventurer Plate in FFXIV.
  2. In WindboundBard, go to BAND → Band Portraits.
  3. Press CAPTURE beside the matching party member (or your own character in Solo mode).
  4. Drag a square inside the screenshot preview, then save the selected portrait.
  5. The locally saved thumbnail appears beside this character's track and instrument assignments.
Privacy: captures are manual and local. Portraits are not sent through the party-chat protocol or automatically shared across PCs.

Ensemble · v0.45.3

Follow the party leader

  1. In BAND → Ensemble, enable Native Ensemble and party-leader sync. Set the FFXIV party leader as Conductor and the other bards as Followers.
  2. Each follower ticks Accept follow requests from this party leader. Permission resets when the party or leader changes.
  3. Regroup between performances and click Follow Party Leader on the conductor. Eligible followers target the leader and submit FFXIV’s native /follow command.

Use the button again once everyone is together after a zone change.

Ensemble · v0.45.0

Rejoin an Ensemble from Concert Director

Enable same-PC concert recovery on every bard. Set the FFXIV party leader to Conductor, give every client the same stage name, assign the parts and start through FFXIV’s Ensemble Ready Check.

If a follower falls behind, choose Rejoin next bar beside that follower in Concert Director. The selected bard returns on the conductor’s next available bar, provided they observed the same native START and have the matching MIDI, assignments and instrument. Use Export Timing Report to record note-dispatch timings.

Resync Ensemble (restart song) stops and re-prepares the entire take. Start it again through the native Ready Check. Whole-set preflight, local rehearsal and concert packs are under the same section.

Setup · v0.44.3

Build a shortcut bar

  1. Go to SETUP → Shortcut Bars, or type /windbound bars. Select Add Windbound example to try the transport and HUD shortcuts.
  2. Use the Bar Manager to add commands, nested categories, labels and spacers. Right-click an on-screen bar or shortcut to edit it.
  3. Dock a bar to an edge or set it to Floating. Assign an F1–F12 hotkey with optional modifiers. Hold a radial hotkey and release on an action, or click into a category while holding the key.
  4. Create a condition set for Performance, combat, duty, party membership or Ensemble role. Select it under Show when.

Enter one slash command per line. Use /wait 1 for a delay, //m0–//m99 for personal FFXIV macros, or //m100–//m199 for shared macros. For a game icon, select Browse game icons and search for a name such as Cheer or a command such as /cheer. Start the query with emote, action, status or item to narrow the results. Select a match to apply its game icon ID.

Use Copy bar and Read clipboard to share Windbound layouts. Imported bars start disabled so you can review the commands and set a hotkey.

Cue a saved macro across the party

  1. In BAND → Ensemble, enable Native Ensemble and leader sync on each client. Set the FFXIV party leader to Conductor and the others to Follower.
  2. Save the intended macro in the same slot on each client. On each follower, open /windbound bars and tick Accept saved-macro cues from this party leader.
  3. On the conductor’s button, enter //pm7 for Individual slot 07 or //pm107 for Shared slot 07. Clicking the button sends the slot number through FFXIV party chat. Each opted-in bard runs their own copy.
Ensemble · v0.44.2

Reduce the scene on background followers

  1. Open BAND → Ensemble on each follower and enable Low-render follower camera.
  2. Enter FFXIV Performance, then focus the conductor window. The follower camera points toward the ground and narrows its field of view.
  3. Focus a follower window or exit Performance to restore its usual view.

The option starts off each time the plugin loads. FFXIV continues rendering a smaller view. To measure the effect on your machine, compare conductor FPS and GPU use with the same song, scene and number of clients.

Ensemble · v0.44.1

Share songs on one PC

In BAND → Ensemble on each client, select Conductor or Follower, enter the same stage name and turn on Sync songs on this PC. Run all clients under the same Windows user account. For an octet, set one Conductor and seven Followers.

Add MIDI files from the conductor’s Songs & Playback tab. The follower receives the copies in their active Ensemble playlist. Sharing uses the local disk, so later followers can pick up the conductor’s current list.

Chapter 15

When the song falls silent

SymptomTry this
Timeline runs, no soundCheck ARM, full Performance UI, instrument, enabled tracks and C3–C6 range.
“Already running”Stop notes and stage movement, then run /windbound recover. ARM again.
Follower stays silentCheck party leader, same MIDI fingerprint, track assignment, follower role and instrument readiness.
Notes sound wrongInspect the track octaves, instrument tags and FFXIV Optimiser suggestions.
Stage dot won’t moveCheck vnavmesh, follower opt-in, the same ward/instance and a walkable destination.
Installer returns 404Check the repository manifest URL, release tag and exact installer asset filename. The repository Plugin.json controls the download; changing it does not require repacking the ZIP.
Installer says disk fullCheck the Windows drive containing %TEMP% and installedPlugins. Other-drive free space does not change the extraction path.
Bassdrum selects BongoUse v0.42.5 or newer. The name matcher recognises Bassdrum as Bass Drum (ID 12); Bongo is ID 11.
MP4 or HD preview controls unavailableStop capture outputs, shut down the idle engine and relaunch the bundled engine.

For full diagnostics, recovery workflows and beta testing, use the official GitHub Wiki. Before sharing reports, remove sensitive local paths or character details.
