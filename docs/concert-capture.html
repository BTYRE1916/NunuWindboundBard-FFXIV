SHOW / NATIVE CAPTURE STUDIO

Let the encore live on.

Record concerts with Windbound’s native Windows engine, MP4 or MKV output, scene and audio controls, replay and an HD preview.

The plugin is your control desk

Capture the concert.
Keep the moment.

Windbound Capture Studio uses a separate native Windows background engine for capture, scene composition, audio mixing and encoding. The plugin supplies its controls, while MIDI transport remains independent.

SHOW → Concert CaptureChoose Native Windbound capture suite

Set up a recording

  1. Install the complete plugin package and keep the CaptureEngine folder beside the plugin DLL. It contains WindboundCaptureEngine.exe and its ffmpeg.exe codec worker.
  2. Open SHOW → Concert Capture. Set Capture option to Native Windbound capture suite.
  3. Choose LAUNCH BACKGROUND ENGINE, or connect to an already running engine. One engine runs per Windows user.
  4. Create a scene, add window/display or other supported sources, arrange layers and configure audio.
  5. With all outputs stopped, open Video, encoding and storage, select the recording folder, encoder, resolution and recording format, then choose APPLY OUTPUT SETTINGS.
  6. Start recording. Use the pause/resume controls as needed, then finish with Stop & Save.

MP4 or MKV, your choice

Choose Recording format → MP4 or MKV before starting output. Recordings and saved replays use the selected container, H.264 video and six stereo AAC tracks.

Let MP4 finish Stop & Save before opening or moving the file. The finalization step makes the recording ready for playback.

A clearer view of the composition

The composed preview offers 540p, HD 720p and Full HD 1080p, with 5, 10 or 15 fps refresh choices. HD 720p at 10 fps is the default. Choose OPEN LARGE PREVIEW for a separate resizable preview window.

Preview quality and refresh rate are separate from the recording’s resolution and frame rate. Source quality, canvas size and available hardware affect what you see.

Scenes, layers and sound

  • Build scenes and arrange sources with position, scale and crop controls.
  • Inspect source properties and supported filters.
  • Use the scene audio mixer and track routing.
  • Configure the replay buffer and save the last moments.
  • Configure and explicitly start a stream from the capture controls when required.

After updating the plugin

An existing capture engine can keep running across a plugin reload. If MP4 or HD preview controls are unavailable, stop recording, streaming and replay output, select SHUT DOWN IDLE ENGINE, then launch the bundled engine again.

The separate Optional OBS connection view remains available for people using local OBS WebSocket controls. The native Windbound suite works with its own engine and bundled codec worker.

Keep room for the performance

The current installer archive is about 76 MiB and expands to roughly 200 MiB. Dalamud uses a temporary extraction directory and an installed copy; allow 1–2 GB free on the Windows drive for installation headroom. Your recording folder also needs enough space for the video itself.
