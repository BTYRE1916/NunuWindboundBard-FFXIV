01 / STUDIO

Edit every part

MIDI Workbench gives you track and note editing, piano-roll selection, undo/redo and verified export.

  • Merge or split voices; rename, reorder, duplicate and remove parts
  • Beat-aware quantization, range repair and sustained voice limiting
  • Custom drum splitting, instrument tags and MIDI/LRC export
Read the guide →
02 / CAPTURE

Record the full concert

Control a separate native Windows engine from SHOW → Concert Capture.

  • Compose scenes and arrange source layers
  • Record MP4 or MKV; pause, resume and save replays
  • 720p / 1080p preview with a large resizable window
Read the guide →
03 / PERFORMANCE

Play MIDI in FFXIV

Load .mid and .midi files and prepare their tracks for the expanded 37-note Performance keyboard.

  • Per-track instruments, octave shifts and guitar tones
  • Full chords or simplified note strategies
  • ARM-controlled native Performance callbacks
Read the guide →
04 / ENSEMBLE

Conduct the orchestra

Assign party tracks and instruments and coordinate a native FFXIV start.

  • Solo, duet, quartet and octet workflows
  • Conductor / Follower roles and readiness checks
  • Each client uses its own matching local MIDI
Read the guide →
05 / ARRANGEMENT

Find the musical roles

Soulweaver generates musician parts and the Optimiser helps fit C3–C6.

  • Deterministic melody, bass and harmony heuristics
  • Named musician-track export with the original tempo map
  • MIDI Inspector for pitch ranges, channels and track diagnostics
Read the guide →
06 / REHEARSAL

Learn and listen

Use Piano Academy, SoundFont rehearsal or a compatible physical MIDI controller.

  • 88-key falling-note practice and wait / play-along modes
  • Local SF2 preview, track audition, volume and speed
  • Live MIDI input and guitar tone controls
Read the guide →
07 / THE SHOW

Build an intermission

Showmaster adds saved local and group emote routines between songs.

  • Unlocked-emote catalog and band availability checks
  • Follower permissions and missing-emote fallbacks
  • Run routines after playback ends and instruments are stowed
Read the guide →
08 / STAGE

Put the band in place

Plan positions and facing with the visual stage designer.

  • Solo and party formation templates
  • Save, restore and adjust stage layouts
  • Optional vnavmesh walking with per-client opt-in
Read the guide →
09 / LIBRARY

Keep the set together

Organise songs, setlists, musician assignments and local band portraits.

  • Solo and Ensemble libraries, tags and favourites
  • Concert snapshots and readiness tools
  • Manual Adventurer Plate portrait capture and cropping
Read the guide →
