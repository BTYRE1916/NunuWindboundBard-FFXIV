SHOW / INTERMISSION

Own the encore.

Saved emote routines and conductor-led choreography for the moments between performances—using emotes each character actually owns.

THE MOMENT BETWEEN SONGS

Give the audience a show.

Showmaster turns intermissions into coordinated stage moments. Build custom sequences of emotes, save them as routines and perform them locally—or have the conductor cue the entire band through verified party messages.

Create a routine

  1. Finish the current song and fully stow the instrument. Showmaster refuses to interrupt active Performance.
  2. Open SHOW → Showmaster. Choose Refresh unlocked emotes to read the current character's available FFXIV emotes.
  3. Create custom routine. Add up to 12 emote steps and select the delays between actions. You can search the library by name.
  4. Try Run local before sending any group commands.
  5. For a band show, have opted-in followers allow group Showmaster controls, then select CHECK BAND EMOTES before GROUP SHOW.

Unlocked on the conductor ≠ unlocked everywhere

The conductor builds routines using their own emote library. Every follower must still have an emote unlocked for their character. The band check reports availability for the selected routine; a missing action can be skipped or replaced with a normal bow, according to that follower's settings.

Designed for intermissions only. Group routines have explicit follower consent, a STOP control and safety checks. They are not arbitrary chat macros and cannot grant account-specific unlocks.
