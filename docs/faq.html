Questions, answered

Before the downbeat.

Practical answers about FFXIV MIDI playback, the new learning and show tools, character portraits, stage facing and compatibility.

Is this the official FINAL FANTASY XIV plugin?

No. Windbound Bard is a community-created Dalamud plugin by Real Nunu. It is not made, approved, or supported by Square Enix or the Dalamud team.

Do I need Dalamud to use Windbound Bard?

Yes. The plugin requires a compatible FFXIV and Dalamud environment. FFXIV updates may temporarily affect compatibility.

What’s the fastest way to install it?

Add the custom plugin repository JSON under /xlsettings → Experimental → Custom Plugin Repositories, then open /xlplugins to install. See the install guide.

Why does the song progress bar move but I hear nothing?

Most often the direct-output ARM switch is off, the full 37-key Performance interface is not open, or the chosen instrument/track is not ready. Run Direct Output & Test → Test C4.

Can I run several Bard characters on one PC?

Windbound’s native ensemble workflow supports same-PC multiple clients. Every client needs its own running plugin state, correctly assigned part and local MIDI.

Do all performers need exactly the same MIDI file?

Yes for the native ensemble file-matching workflow. The conductor sends a MIDI fingerprint; it does not send the file itself. The local file path can differ.

Does the conductor automatically start the next ensemble song?

No. Concert Director can prepare the next song, but native Ensemble START remains an explicit action under the conductor’s control.

Do followers need to click Ready Check manually?

The plugin offers optional automatic acceptance of the FFXIV Ensemble Ready Check when the client is correctly configured and ready. Manual confirmation remains possible.

Can I use a real MIDI piano keyboard?

Yes, Windbound includes Live MIDI Piano with controller input. Its actual operation depends on the system’s MIDI backend and device compatibility.

Does SoundFont preview broadcast audio to my party?

No. SF2 SoundFont preview plays through your local speakers for rehearsal. It does not send audio to the FFXIV party.

Will stage formations teleport or turn my characters?

No teleporting. Solo Stage and opted-in party formations can walk using optional vnavmesh; v0.35+ adds automatic facing after arriving. Exact behaviour depends on the plugin build and game compatibility, and must be tested in a safe area.

Why are the release and manual version numbers different?

GitHub release tags (such as FFXIVMIDIPLAYER-v1.40) are separate from the plugin assembly/source version (such as v0.39). The old single-file manual began at v0.32; this site has been updated to reflect the v0.39 source. Always check the version actually installed and read the matching release notes.

How do I find Piano Academy in the new layout?

Open STUDIO → Piano Academy. Load a MIDI and connect your USB synthesizer for falling-note lessons. See the practice guide.

Does Piano Academy send notes into FFXIV?

No. It is a local learning view of the original MIDI pitches, with an 88-key keyboard. The regular Live MIDI Piano and FFXIV Performance features remain separate.

Why are some Showmaster emotes unavailable to my band?

The conductor can select emotes they own, but followers must unlock the same emotes on their own characters. Use CHECK BAND EMOTES before GROUP SHOW; a follower can skip a locked step or use a bow fallback.

Can Showmaster run during a song?

No. Routines are designed for intermissions; the plugin requires MIDI playback to end and Performance instruments to be stowed before executing emotes.

Where are the Band Portraits controls?

Open BAND → Band Portraits, even in Solo mode. Open an Adventurer Plate in FFXIV, click CAPTURE, drag a square inside the preview and save. See the portrait guide.

Do saved band pictures appear on my friends' computers?

No. The cropped Adventurer Plate images are saved locally on the client that captures them and are not automatically transmitted through party chat.

Can I use Dark Stage colours without animations?

Yes. Use SETUP → Appearance to select your accent colour, turn off the subtle animated highlight, or switch to Plain colours.

Does changing the FFXIV patch affect native features?

It may. Game-facing functions such as instrument switching, UI capture and automatic facing should be tested against the currently supported FFXIV/Dalamud build. Keep a known-good plugin backup.
