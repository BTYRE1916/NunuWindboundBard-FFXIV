Questions, answered

Before the downbeat.

Answers about installation, the MIDI Workbench, instruments, native capture, ensembles and the tools around your performance.

Can my octet share MIDI files on one PC?

Set one client to Conductor and seven to Follower, use the same Windows user account and Ensemble stage, and enable Sync songs on this PC on all eight clients. Follow the setup guide.

Where is the full MIDI Editor?

In v0.44.0, open STUDIO → MIDI Editor. It supports MIDI timeline and controller editing, tempo and meter changes, SoundFont or MIDI device playback, and recording. Read the MIDI Editor guide.

Where is the MIDI Workbench?

Open STUDIO → MIDI Workbench. It supports track and note editing, drum splitting, pitch/range tools, preview, undo/redo and MIDI/LRC export. Read the Workbench guide.

Does Workbench overwrite my source MIDI?

It edits an independent working copy and saves to a new output file. Export before unloading the plugin or importing another song; working copies last for the current session.

Will my octave tags be applied twice?

The piano roll shows stored pitches. Preview applies the part’s octave tag once and export preserves the directive. Bake octave tags applies the shift to notes and clears the tag. C3–C6 adaptation also resolves it.

Why should I mark a track as a GM drum kit?

GM drum notes identify different hit types. A prepared FFXIV drum part already uses musical pitches. Workbench preserves named parts such as Bassdrum; mark a part as a GM kit only when you intend to convert its GM hit identifiers.

Why did Bassdrum used to load Bongo?

Before v0.42.5, the joined Bassdrum spelling fell through to a generic drum match. The updated matcher selects Bass Drum (ID 12). Bongo remains ID 11.

Do I need OBS for native capture?

The Native Windbound capture suite uses its own background Windows engine and bundled ffmpeg.exe worker. A separate optional OBS connection remains available for existing local OBS workflows.

How do I select MP4 recording?

With recording, streaming and replay stopped, open Video, encoding and storage → Recording format → MP4, then APPLY OUTPUT SETTINGS. Finish MP4 recordings using Stop & Save. Recording guide.

How do I improve the capture preview?

Select 720p or 1080p and choose a 5/10/15 fps refresh rate. OPEN LARGE PREVIEW creates a separate resizable view. These settings are independent of recording resolution.

Why are MP4 or HD controls missing after an update?

An older background engine may still be running. Stop all outputs, select SHUT DOWN IDLE ENGINE and launch the updated bundled engine.

Does a download-URL change require repacking the installer?

No. The repository root Plugin.json controls the download before extraction starts. Its install/update links must match an existing release tag and asset filename. The internal NunuWindboundBard.json, DLL and repository assembly version must also agree.

Why does installation say there is not enough space?

Dalamud extracts into the Windows temporary directory, usually on C:, then copies into installedPlugins. The current package expands to about 200 MiB. Allow 1–2 GB free on that drive and remove failed installer temporary folders with the game and launcher closed.

Which ZIP should I attach for plugin installation?

Use the compiled installer ZIP unchanged. A full-project source archive is for development. A .7z archive renamed to .zip is still a 7-Zip file and cannot substitute for a real ZIP.

Why can a Workbench export report channel capacity?

Standard MIDI has 15 melodic program channels plus drums. Many distinct sounds or overlapping copies of the same pitch can exceed those channels. Reduce the instrument set, clean duplicates, trim overlaps or export fewer parts together.

Is this the official FINAL FANTASY XIV plugin?

No. Windbound Bard is a community-created Dalamud plugin by Real Nunu. It is not made, approved, or supported by Square Enix or the Dalamud team.

Do I need Dalamud to use Windbound Bard?

Yes. The plugin requires a compatible FFXIV and Dalamud environment. FFXIV updates may temporarily affect compatibility.

What’s the fastest way to install it?

Add the custom plugin repository JSON under /xlsettings → Experimental → Custom Plugin Repositories, then open /xlplugins to install. See the install guide.

Why does the song progress bar move but I hear nothing?

Most often the direct-output ARM switch is off, the full 37-key Performance interface is not open, or the chosen instrument/track is not ready. Run Direct Output & Test → Test C4.

Can I run several Bard characters on one PC?

Windbound’s native ensemble workflow supports same-PC multiple clients. Every client needs its own running plugin state, correctly assigned part and local MIDI.

Do all performers need exactly the same MIDI file?

Yes for the native ensemble file-matching workflow. The conductor sends a MIDI fingerprint; it does not send the file itself. The local file path can differ.

Does the conductor automatically start the next ensemble song?

No. Concert Director can prepare the next song, but native Ensemble START remains an explicit action under the conductor’s control.

Do followers need to click Ready Check manually?

The plugin offers optional automatic acceptance of the FFXIV Ensemble Ready Check when the client is correctly configured and ready. Manual confirmation remains possible.

Can I use a real MIDI piano keyboard?

Yes, Windbound includes Live MIDI Piano with controller input. Its actual operation depends on the system’s MIDI backend and device compatibility.

Does SoundFont preview broadcast audio to my party?

No. SF2 SoundFont preview plays through your local speakers for rehearsal. It does not send audio to the FFXIV party.

Will stage formations teleport or turn my characters?

No teleporting. Solo Stage and opted-in party formations can walk using optional vnavmesh; v0.35+ adds automatic facing after arriving. Exact behaviour depends on the plugin build and game compatibility, and must be tested in a safe area.

How do release tags, installer filenames and plugin versions relate?

The published plugin assembly is 0.44.1.0. The GitHub tag is 0.44.1 and the installer filename is FFXIVMIDIPLAYER-BY-NUNU-v0.44.1.zip. Dalamud reads the exact download URLs in the repository manifest.

How do I find Piano Academy in the new layout?

Open STUDIO → Piano Academy. Load a MIDI and connect your USB synthesizer for falling-note lessons. See the practice guide.

Does Piano Academy send notes into FFXIV?

No. It is a local learning view of the original MIDI pitches, with an 88-key keyboard. The regular Live MIDI Piano and FFXIV Performance features remain separate.

Why are some Showmaster emotes unavailable to my band?

The conductor can select emotes they own, but followers must unlock the same emotes on their own characters. Use CHECK BAND EMOTES before GROUP SHOW; a follower can skip a locked step or use a bow fallback.

Can Showmaster run during a song?

No. Routines are designed for intermissions; the plugin requires MIDI playback to end and Performance instruments to be stowed before executing emotes.

Where are the Band Portraits controls?

Open BAND → Band Portraits, even in Solo mode. Open an Adventurer Plate in FFXIV, click CAPTURE, drag a square inside the preview and save. See the portrait guide.

Do saved band pictures appear on my friends' computers?

No. The cropped Adventurer Plate images are saved locally on the client that captures them and are not automatically transmitted through party chat.

Can I use Dark Stage colours without animations?

Yes. Use SETUP → Appearance to select your accent colour, turn off the subtle animated highlight, or switch to Plain colours.

Does changing the FFXIV patch affect native features?

It may. Game-facing functions such as instrument switching, UI capture and automatic facing should be tested against the currently supported FFXIV/Dalamud build. Keep a known-good plugin backup.
