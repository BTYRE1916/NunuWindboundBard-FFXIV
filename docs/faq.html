Questions, answered

Before the downbeat.

A few things every Bard should know, from MIDI file matching to plugin safety, native Ensemble timing and what the stage designer can really do.

Is this the official FINAL FANTASY XIV plugin?

No. Windbound Bard is a community-created Dalamud plugin by Real Nunu. It is not made, approved, or supported by Square Enix or the Dalamud team.

Do I need Dalamud to use Windbound Bard?

Yes. The plugin requires a compatible FFXIV and Dalamud environment. FFXIV updates may temporarily affect compatibility.

What’s the fastest way to install it?

Add the custom plugin repository JSON under /xlsettings → Experimental → Custom Plugin Repositories, then open /xlplugins to install. See the install guide.

Why does the song progress bar move but I hear nothing?

Most often the direct-output ARM switch is off, the full 37-key Performance interface is not open, or the chosen instrument/track is not ready. Run Direct Output & Test → Test C4.

Can I run several Bard characters on one PC?

Windbound’s native ensemble workflow supports same-PC multiple clients. Every client needs its own running plugin state, correctly assigned part and local MIDI.

Do all performers need exactly the same MIDI file?

Yes for the native ensemble file-matching workflow. The conductor sends a MIDI fingerprint; it does not send the file itself. The local file path can differ.

Does the conductor automatically start the next ensemble song?

No. Concert Director can prepare the next song, but native Ensemble START remains an explicit action under the conductor’s control.

Do followers need to click Ready Check manually?

The plugin offers optional automatic acceptance of the FFXIV Ensemble Ready Check when the client is correctly configured and ready. Manual confirmation remains possible.

Can I use a real MIDI piano keyboard?

Yes, Windbound includes Live MIDI Piano with controller input. Its actual operation depends on the system’s MIDI backend and device compatibility.

Does SoundFont preview broadcast audio to my party?

No. SF2 SoundFont preview plays through your local speakers for rehearsal. It does not send audio to the FFXIV party.

Will stage formations teleport or turn my characters?

No. Optional vnavmesh walking requires follower opt-in and explicit commands. Movement is bounded by safety checks, and automatic facing is not included in the referenced version.

Why are the release and manual version numbers different?

The repository’s detailed manual is marked v0.32 while its published release tag and plugin assembly version use separate numbering. Check the installed plugin build and the release page for the version you actually have.
