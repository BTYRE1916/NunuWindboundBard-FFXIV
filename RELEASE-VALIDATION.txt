Windbound Bard v0.9 — Multi-Device Ensemble (source build)

Scope:
- New Core/MultiDeviceEnsemble.cs private TCP conductor/follower session
- Opt-in setting, host/join controls, no auto-connect on plugin load
- Authenticated code pairing, 4 MB MIDI transfer, SHA-256 verification
- Song arrangement and party track assignment propagation
- Clock samples, readiness acknowledgements, scheduled cross-PC START/STOP
- Independent Solo/Ensemble saved playlists and original local same-PC mode kept
- Tests/MultiDeviceTransportSmokeTest.csproj + Run-v0.9-Tests.ps1

Source inspection and archive checks run in Linux environment; Windows .NET SDK
and FFXIV are not installed. Actual compiling, performance, firewall/network
behaviour and two-PC synchronization still require user tests on Windows.

Security: The transport is not encrypted. Use only trusted LAN or encrypted
private network (Tailscale). NEVER expose/port-forward its listener on the
public Internet. Stage code is held in RAM only and not saved.

Windbound Bard v0.10 -- Reliable Auto Next / Song Transitions
- Fixed Draw()-dependent song advancement by calling PollSongTransitions from Framework.Update after Player.Update.
- Queued manual file changes, Next, and Play pressed during an outstanding Stop request.

- C# / Windows / Dalamud compile and live FFXIV tests still required.

Windbound Bard v0.11 -- Soulweaver Studio
- New rule-based arranger produces one musician part per performer (1/2/4/8), defaults to preserving every prepared note.
- Musical register/voice role analysis, estimated key, phrase and chord-onset reports, and part timeline preview.
- New MIDI writer preserves tempo changes, time signature, key signature and relative note timing.
- One named format-1 MIDI track per performer with import-ready track/channel identifiers for existing conductor assignments.
- User can override suggested instruments and party recipients, and export into separate Solo/Ensemble playlist profiles.
- Per-original-MIDI preset preferences persist; previous v0.10 saved settings are migrated additively to version 11.
- Songs & Playback, native Performance output, ensemble, networking, instruments, guitar tones, and transition files are unchanged apart from new UI integration.
- Tests/SoulweaverSmokeTest.csproj and Samples/Soulweaver-Quartet-Demo.mid included.
- The C# project and new core test need compilation/testing on Windows with .NET 10 and Dalamud API 15. This archive contains no prebuilt DLL.
