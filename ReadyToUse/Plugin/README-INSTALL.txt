Windbound Bard v0.43.1.0
Windows x64 / Dalamud API 15

Windbound's main window has a new Hide Game Performance HUD button below the
language selector. The native keyboard, guitar tone selector, and metronome
become transparent while their windows stay open for playback. Use Show Game
Performance HUD to restore their opacity.

Keep CaptureEngine beside NunuWindboundBard.dll.
